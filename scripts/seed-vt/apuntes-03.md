## Para practicar esta quincena

- **gitleaks**: el scanner que uso en pre-commit. Se configura en cinco minutos.
- **OverTheWire Bandit**: niveles cortos de Linux y permisos. Los primeros son muy amables.
- **OWASP API Security Top 10**: leé API2 y API8, que son los que más veo en repos.

:::block{label="3 · Pregunta de carrera"}
## ¿Sirve un README de GitHub si no tengo experiencia laboral?

> «Tengo proyectos de la facu pero ningún laburo. ¿Vale la pena armar el perfil?»

Sí, y para mí es justo el caso donde más sirve. Sin experiencia, lo único que alguien puede evaluar es lo que hiciste. Un README que explica qué problema resuelve el proyecto, cómo correrlo y qué aprendiste vale más que diez repos sin descripción.

El criterio: si alguien entra a tu perfil y no entiende rápido qué sabés hacer, el perfil no está trabajando para vos.
:::

:::block{label="4 · Herramienta"}
## `ss -tulpn`

Muestra qué está escuchando en cada puerto y qué proceso lo abrió. Cuando algo dice «address already in use», es lo primero que corro. Reemplaza a `netstat`, que en muchas distros ya no viene.
